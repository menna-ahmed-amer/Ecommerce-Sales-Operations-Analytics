# Power BI Report

**Final report (open with Power BI Desktop):** [`Olist_Ecommerce_Analysis.pbix`](https://github.com/menna-ahmed-amer/Ecommerce-Sales-Operations-Analytics/releases/download/v1.0.0/Olist_Ecommerce_Analysis.pbix)  
**Storage:** This `.pbix` is attached to the [v1.0.0 GitHub Release](https://github.com/menna-ahmed-amer/Ecommerce-Sales-Operations-Analytics/releases/tag/v1.0.0), not stored in the repository folder.  
**Author:** Menna Ahmed Amer

This report contains six interactive analytical pages covering executive overview, sales and products, customers and geography, delivery and reviews, seller performance, and payments.

## Open and review

1. Download the `.pbix` file and open it using **Microsoft Power BI Desktop**.
2. Review the six report pages and the actual relationship model.
3. To **refresh** the report, open **File → Options and settings → Data source settings** and update any SQL Server instance names, database settings, or local file paths to your environment.
4. If you rebuild the source tables, consult [`../docs/REPRODUCIBILITY.md`](../docs/REPRODUCIBILITY.md) and check the KPI reconciliation notes before refreshing.

The included `.pbix` is structurally readable as a Power BI package. It has **not been interactively refreshed or opened in Power BI Desktop during GitHub packaging**, so local credentials/source-path adjustments may still be required.

For quick review without Power BI Desktop, see the [dashboard screenshots](../images/) and [screenshot PDF gallery](../reports/Dashboard_Screenshot_Gallery.pdf). The gallery is a compilation of original images, not an export from Power BI Desktop.
